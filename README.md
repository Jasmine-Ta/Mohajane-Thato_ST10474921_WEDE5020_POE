# Sunrise Acres Farm - Website Update

This repository contains the production-ready front-end source files for the **Sunrise Acres Farm** ecosystem. The platform has been entirely refactored from unstyled structural prototypes into a fully integrated, mobile-responsive web experience utilizing a singular, shared CSS layout architecture.

## Local Development Deployment

To spin up the web platform locally:
1. Clone or download this project directory to your workspace.
2. Verify that your local folder layout mirrors the **Project Directory Tree** below.
3. Open `index.html` within any modern desktop or mobile web browser.

 Tech Stack & Standards Matrix

* **Markup Layer:** Clean, semantic HTML5 document layouts.
* **Presentation Engine:** Advanced CSS3 utilizing standard Flexbox axis tracks, explicit two-dimensional CSS Grid alignments, centralized `:root` branding token custom variables, and responsive media breakpoint layers.
* **Typography Core:** Clean, scalable relative system units (`rem`, `%`) built off a base font scale pattern.
